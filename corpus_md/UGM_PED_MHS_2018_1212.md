# Panduan Input Data Prestasi dan Organisasi v.1

Panduan Input Data Prestasi dan Organisasi

1. Buka simaster.ugm.ac.id pada web browser anda, kemudian klik “Sign in with SSO UGM”.
Silakan masuk menggunakan email ugm anda.

2. Kemudian pilih menu “Kemahasiswaan”

3. Silakan klik menu Sang Juara kemudian pilih menu Prestasi. Untuk menambahkan daftar prestasi mahasiswa silakan klik tombol biru Tambah Prestasi pada bagian atas.

4. Silakan pilih bidang prestasi yang akan ditambahkan, kemudian klik pilih.

5. Silakan isi data sesuai kolom yang tersedia. Setelah terisi semua silakan klik Simpan

6. Setelah data dan berkas anda isi dan berhasil tersimpan, silakan datang ke Petugas Fakultas untuk melakukan Verifikasi dengan membawa Berkas Asli.
