# 9. Juknis Pendaftaran RUD – Website Inspirasi

Pendaftaran Riset Unggulan Daerah 2024 Pekalongan, 27 Februari 2024 Beranda RUD Keterangan :
• Halaman Awal Sebelum Login/Register • Klik tombol Login Sistem untuk masuk ke sistem • Klik tombol Panduan untuk melihat panduan/ petunjuk teknis pendaftaran RUD • Kilk tombol Daftarkan Riset Anda • Apabila belum login maka akan diarahkan ke halaman login • Apabila sudah login maka akan diarahkan ke halaman tambah data RUD Login RUD Keterangan :
• Silahkan login menggunakan NIK dan Password apabila sudah memiliki akun RUD • Apabila belum memiliki akun silahkan bisa mendaftar dengan menekan tombol Daftar Akun • Tombol Beranda untuk kembali ke halaman beranda Registrasi Akun RUD Keterangan :
• Silahkan daftar akun RUD menggunakan NIK dan Password apabila anda belum memiliki akun • Isi data dan klik tombol Daftar sistem akan memvalidasi data, apabila data valid maka akun berhasil dibuat dan sistem akan mengarahkan menuju halaman Login Data RUD Keterangan :
• Silahkan klik tombol Tambah Data untuk menuju halaman Formulir Pendaftaran RUD Formulir RUD Bagian Keterangan :
• Berikut merupakan halaman formulir RUD bagian 1 • Terdiri dari inputan data peneliti dan anggota • Klik tombol selanjutnya untuk menuju halaman selanjutnya Formulir RUD Bagian Keterangan :
• Berikut merupakan halaman formulir RUD bagian 2 • Terdiri dari inputan Profil Lembaga Pengusul/Peneliti • Klik tombol selanjutnya untuk menuju halaman selanjutnya • Klik tombol sebelumnya untuk kembali ke halaman sebelumnya Formulir RUD Bagian Keterangan :
• Berikut merupakan halaman formulir RUD bagian 3 • Terdiri dari inputan Dokumen Usulan/Proposal • Klik tombol selanjutnya untuk menuju halaman selanjutnya • Klik tombol sebelumnya untuk kembali ke halaman sebelumnya Formulir RUD Bagian Keterangan :
• Berikut merupakan halaman formulir RUD bagian 4 • Terdapat tombol Simpan Data, klik tombol tersebut untuk menyimpan keseluruhan data • Klik tombol sebelumnya untuk kembali ke halaman sebelumnya Formulir RUD ( ketika data tidak lengkap ) Keterangan :
• Berikut merupakan halaman formulir RUD ketika data yang disimpan tidak lengkap • Terdapat pesan peringatan Data Gagal Disimpan, selanjutnya user diharuskan melengkapi data yang belum lengkap Data RUD ( ketika data lengkap ) Keterangan :
• Berikut merupakan halaman data RUD ketika data berhasil disimpan • Terdapat pesan Data Berhasi Disimpan, selanjutnya user diharuskan cek kembali data yang sudah disimpan sebelum mengirimkannya ke admin Data RUD (Status : Draft) Keterangan :
• Berikut merupakan halaman data RUD ketika data berhasil disimpan dan masih dalam status Draft • Terdapat beberapa tombol aksi yang bisa digunakan oleh user Hapus Data Berfungsi untuk menghapus data RUD yang anda pilih Edit Data Berfungsi untuk mengubah data RUD yang anda pilih Kirim Data Berfungsi untuk mengirim data RUD dan sekaligus mengunci data agar tidak bias diubah lagi Detail Data Berfungsi untuk melihat detail data RUD yang anda pilih Data RUD (Detail Data) Keterangan :
• Berikut merupakan halaman data RUD ketika tombol detail data diklik Data RUD (Edit Data) Keterangan :
• Berikut merupakan halaman data RUD ketika tombol Edit Data diklik • User dapat mengubah data RUD, apabila masih terdapat data yang keliru selama data belum dikirm dan terkunci Data RUD ( Hapus Data) Keterangan :
• Berikut merupakan halaman data RUD ketika tombol Hapus Data diklik • User dapat menghapus data RUD apabila mengurungkan niat untuk mengajukan proposal RUD • Hapus data dapat dilakukan selama data belum dikirm dan terkunci Data RUD ( Kirim Data) Keterangan :
• Berikut merupakan halaman data RUD ketika tombol kirim data diklik • Terdapat pesan peringatan kirim data, tekan tombol Iya jika user yakin data sudah benar semua • Tekan tombol Batal jika urung mengirimkan data • Setelah data berhasil terkirim, maka user hanya bisa melihat detail data tanpa bisa lagi edit maupun hapus data Data RUD (Status :
Verifikasi Proposal) Keterangan :
• Berikut merupakan halaman Data RUD dengan status Verifikasi Proposal Data RUD (Status :
Lolos Administrasi ) Keterangan :
• Berikut merupakan halaman Data RUD dengan status Lolos Administrasi Data RUD (Status :
Gagal Lolos Administrasi ) Keterangan :
• Berikut merupakan halaman Data RUD dengan status Gagal Lolos Administrasi Alur Logout Sistem Keterangan :
• Berikut merupakan alur Logout dari sistem • Klik tombol Icon User • Muncul tombol Logout, klik tombol logout • Muncul pesan peringatan logout, tekan Iya untuk logout, tekan Batal untuk membatalkan logout sistem • Ketika tombol Iya diklik maka user akan keluar dari sistem dan setelah itu akan diarahkan ke halaman login Pendaftaran Riset Unggulan Daerah 2024 Website :
