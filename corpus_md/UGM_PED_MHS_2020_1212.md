# PANDUAN MENDAFTAR BEASISWA SECARA DARING MELALUI SIMASTER rev.2

PANDUAN MENDAFTAR BEASISWA SECARA DARING MELALUI SIMASTER

1. Buka laman simaster.ugm.ac.id pada web browser anda, masukkan username dan password kemudian klik “Sign In”

2. Selanjutnya pada layar sebelah kiri, pilih menu Kemahasiswaan → Beasiswa

3. Untuk melihat Beasiswa yang sedang ditawarkan silakan klik pada tab menu Penawaran Beasiswa. Untuk mendaftar beasiswa silakan klik tombol yang terletak di sebelah kanan sesuai lajur nama beasiswa.

4. Selanjutkan akan muncul informasi dan syarat untuk mendaftar Beasiswa. Apabila Beasiswa ditawarkan untuk Program Studi anda, maka ada notifikasi Beasiswa ini tersedia untuk Program Studi Anda. Klik tombol “Daftar Beasiswa” untuk mendaftar beasiswa.

5. Setelah klik Daftar Beasiswa, maka akan mucul Prasyarat Administrasi. Apabila anda termasuk dalam kriteria, maka muncul notifikasi Terpenuhi pada kolom Keterangan. Untuk melanjutkan proses pendaftaran beasiswa, silakan klik tombol “Simpan dan Lanjut”.

6. Selanjutnya anda diminta untuk mengisi data dan berkas untuk pendaftaran beasiswa. Untuk melihat data orangtua, silakan klik tab menu Data Orang Tua. Apabila data tidak sesuai, silakan edit dengan klik tombol

7. Setelah selesai mengubah data orang tua, klik tombol “Ubah” untuk menyimpan perubahan data.

8. Untuk melihat data saudara, silakan klik tab menu Data Saudara. Apabila data tidak sesuai, silakan edit dengan klik tombol atau klik tombol untuk menghapus data

9. Pada tampilan mobile, tab menu Data Saudara dsb dapat ditampilkan dengan klik tombol

10. Apabila data sudah selesai diubah, klik tombol “Ubah” untuk menyimpan data.

11. Untuk menambahkan data saudara, klik tombol “Tambah”.

12. Setelah selesai mengisikan data saudara, klik tombol “Tambah” untuk menyimpan data.

13. Kemudian tab menu Riwayat Studi digunakan untuk melihat history nilai akademik. Data yang ditampilkan sudah terintegrasi dan tidak dapat anda rubah.

14. Selanjutnya tab menu Dokumen untuk mengunggah berkas syarat pendaftaran beasiswa. Tab menu Dokumen terintegrasi dengan menu DMS (Data Management System). Untuk memulai unggah berkas klik tombol

15. Kemudian pilih berkas sesuai dengan berkas yang diminta. Klik “Pilih Berkas” untuk menyimpan

16. Pastikan file sudah berhasil tersimpan. Untuk menampilkan file, silakan klik tombol

17. Apabila saat upload berkas yang akan disertakan dalam pendaftaran beasiswa belum diunggah.
Silakan klik tombol “DMS”. Pastikan berkas yang diunggah sesuai dengan Jenis Berkas.

18. Isi data sesuai dengan permintaan. Pastikan Jenis Berkas sudah sesuai dengan permintaan. Untuk memilih file yang akan diunggah klik Choose File, ukuran file yang diunggah tidak boleh lebih dari 5 MB. Untuk menyimpan dan mengunggah berkas, klik “Upload”.

19. Pastikan berkas berhasil terunggah.

20. Selanjutnya tab menu Data Pendukung digunakan untuk memasukkan data pendukung lainnya sesuai dengan persyaratan beasiswa. Silakan isi sesuai dengan permintaan data. Klik “Simpan”
untuk menyimpan data.

21. Setelah pengisian data dan berkas selesai, untuk melakukan pengajuan pendaftaran beasiswa silakan klik tombol “Simpan Draf Beasiswa”

22. Selanjutnya akan muncul pernyataan kebenaran data dan berkas yang diunggah. Apabila sudah yakin benar, klik “Setuju” untuk mendaftar beasiswa.

23. Anda akan diarahkan ke tab menu “Riwayat Pengajuan Beasiswa”. Untuk melamar beasiswa, silakan klik tombol .

24. Untuk mengajukan beasiswa, klik tombol “Ya”. Setelah beasiswa diajukan, anda tidak dapat mengubah data dan berkas.

25. Status pengajuan beasiswa anda akan berubah menjadi Melamar. Untuk melihat riwayat pengajuan beasiswa klik tombol detail

26. Berikut tampilan riwayat pengajuan beasiswa.

27. Apabila berkas atau data pengajuan beasiswa anda ditolak, maka terdapat notifikasi dan komentar mengenai kesalahan/kekurangan data anda. Status pengajuan beasiswa anda akan berubah menjadi Draft kembali.

28. Untuk memperbaiki kesalahan/kekurangan data atau berkas pengajuan beasiswa anda, silakan menuju tab menu Riwayat Pengajuan Beasiswa. Kemudian klik tombol ubah beasiswa

29. Setelah selesai memperbaiki data/berkas, kembali ke tab menu Riwayat Pengajuan Beasiswa.
Kemudian klik tombol ajukan beasiswa

30. Untuk mengajukan beasiswa, klik tombol “Ya”. Setelah beasiswa diajukan, anda tidak dapat mengubah data dan berkas.

31. Status anda berubah menjadi Melamar. Selalu pantau riwayat pengajuan beasiswa melalui tombol detail supaya tidak ketinggalan informasi seleksi beasiswa.
